فاز ۱.۲: لایه قراردادهای عمومی کرنل آریا

- پاکت دستور و پاکت رویداد نسخه‌دار با correlation_id و تست رفت‌وبرگشت سریال‌سازی
- قرارداد مانیفست پلاگین + اسکیمای JSON مرجع + اعتبارسنجی ساختاری و semver
- قرارداد JSON-RPC 2.0 (درخواست/پاسخ/خطا، توکن نشست، سقف ۱۰ مگابایت، مهلت ۳۰ ثانیه، رجیستری متد)
- ۱۰ تریت سرویس کرنل شامل PluginHostServices با الزام مجوز
- قرارداد خطا با بازه‌های کد پایدار مجزا برای ۹ موتور + بار خطای RPC
- سیاست نسخه‌گذاری کامل (کرنل، API پلاگین، اسکیما، بکاپ، رویداد) با ابزارهای سازگاری
- ۸ سند قراردادی کامل به فارسی؛ ۲۵ تست سبز؛ clippy بدون هشدار
